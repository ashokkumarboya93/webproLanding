# WebPro Analytics — Landing Page

> A state-of-the-art, privacy-first behavioral analytics, Microsoft Clarity-grade heatmap, and session replay platform landing page built with the **MongoDB Bright Design System**.

---

## 🚀 Features

- **MongoDB Bright Aesthetic**: Designed with Canvas Off-White (`#F9FBFA`), Obsidian Slate (`#001E2B`), Spring Green (`#00ED64`), and Deep Emerald (`#00684A`).
- **Interactive Hero Mockup**: 3D-tilted executive dashboard with real-time mouse tracking, Clarity-style dynamic scroll depth line (`"65.4% Users Reached This Point"`), and pulsing thermal hotspots with diagnostics.
- **Bento Grid Feature Matrix**:
  - Clarity-grade Heatmaps (Clicks, Scroll Reach %, Rage Clicks)
  - Privacy-first DOM Session Replay with interactive timeline scrubber & PII masking
  - AI Root-Cause Anomaly Detection with natural language insights
  - Retroactive Conversion Funnels with drop-off percentages
- **1-Line Installation Playground**: Tabbed framework code switcher (HTML, React/Next.js, Vue/Nuxt, Shopify) with live beacon test simulator & confetti.
- **Interactive Pricing Calculator**: Dynamic traffic slider and Annual / Monthly discount toggle.
- **Comparison Matrix Table**: WebPro vs. Microsoft Clarity vs. Hotjar.
- **Live Sandbox Demo Modal**: Fully interactive browser environment to simulate rage clicks, dead clicks, and DOM telemetry events.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3**
- **Tailwind CSS** (MongoDB Bright Palette Configuration)
- **Vanilla JavaScript (ES6+)**
- **Lucide Icons**
- **Canvas Confetti**

---

## 💻 Quick Start

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx (if installed)
npx serve .
```
